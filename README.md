# Awesome-Mobile-CRM-App

# Top Mobile CRM App Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Mobile-First Sales Enablement, Offline Access & Field Productivity*  
**Last updated: March 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Mobile CRM Apps**. These tools give sales teams and field professionals access to contacts, deals, tasks, and communication tools from smartphones and tablets — supporting offline data access, push notifications, call logging, and location-aware features.

**Examples** include Salesforce Mobile App, HubSpot Mobile App, Zoho CRM Mobile, Pipedrive Mobile, Freshsales Mobile, Microsoft Dynamics 365 Mobile, SugarCRM Mobile, Zendesk Sell Mobile, Copper Mobile, and Close Mobile (the category leaders).

**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, custom mobile CRM workflows, and transparent customer data — ideal for privacy-conscious businesses, developers, and organizations seeking data-sovereign mobile CRM platforms.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms

- **[Salesforce Mobile App](https://www.salesforce.com/)**  
  Salesforce's native mobile app with offline access, voice notes, business card scanning, and Einstein AI insights for field sales.

- **[HubSpot Mobile App](https://www.hubspot.com/)**  
  Mobile CRM app with contact management, deal pipeline, task reminders, and integrated calling for sales teams.

- **[Zoho CRM Mobile](https://www.zoho.com/crm/)**  
  Mobile CRM with offline access, voice notes, business card scanning, and AI-powered sales assistant.

- **[Pipedrive Mobile](https://www.pipedrive.com/)**  
  Sales CRM mobile app with pipeline view, deal tracking, activity reminders, and call logging.

- **[Freshsales Mobile](https://www.freshworks.com/freshsales-crm/)**  
  Mobile CRM with AI-powered lead scoring, built-in phone, and email tracking for sales reps on the go.

- **[Microsoft Dynamics 365 Mobile](https://www.microsoft.com/en-us/dynamics-365)**  
  Enterprise CRM mobile app with offline access, Power Apps integration, and AI-driven insights.

- **[SugarCRM Mobile](https://www.sugarcrm.com/)**  
  Mobile CRM app for SugarCRM with offline access, custom modules, and activity management.

- **[Zendesk Sell Mobile](https://www.zendesk.com/sell/)**  
  Sales CRM mobile app with pipeline management, call logging, and location-based insights.

- **[Copper Mobile](https://www.copper.com/)**  
  Mobile CRM app integrated with Google Workspace for contact management and deal tracking.

- **[Close Mobile](https://close.com/)**  
  Sales CRM mobile app with built-in calling, SMS, and email with offline access.

## Open-Source GitHub Projects

- **[BottleCRM](https://github.com/Django-CRM/Django-CRM)**  
  Free, self-hosted, multi-tenant CRM built with Django REST Framework, SvelteKit, and Flutter for native iOS/Android mobile apps. MIT licensed, unlimited users, no feature paywall. Features PostgreSQL Row-Level Security for tenant isolation, helpdesk with SLA timers, and agent-ready REST API [citation:8].

- **[Twenty](https://github.com/twentyhq/twenty)**  
  Modern open-source CRM with a growing ecosystem of native mobile clients. Self-hosted or cloud-deployable with contacts, companies, opportunities, tasks, and custom objects. AGPL-3.0 licensed.

- **[TwentyMobile](https://github.com/andrealuciano/twentymobile)**  
  Native mobile app for Twenty CRM with business card scanning, voice-to-text notes, smart reminders, and 100% offline-first architecture. Data transits exclusively between device and self-hosted server. AGPL-3.0 licensed [citation:4].

- **[Viginti – Twenty Client](https://apps.apple.com/jp/app/viginti-twenty-client/id6782863969)**  
  Native iOS/iPadOS/Mac client for Twenty CRM with full offline support, business card scanner, document scanner, voice notes with on-device transcription, and Siri Shortcuts. Free read-only tier with Pro subscription for editing [citation:16].

- **[SuiteCRM Mobile](https://github.com/salesagility/SuiteCRM)**  
  Community mobile companion apps for SuiteCRM with real-time access to Accounts, Contacts, Leads, and Opportunities. Offline mode with queued updates and REST API v11+ sync [citation:9].

- **[TapCRM](https://store.suitecrm.com/addons/tapcrm/reviews/)**  
  Mobile app for SuiteCRM with field service features including live tracking and full CRM data access from mobile [citation:2].

- **[YouCRM for SuiteCRM](https://play.google.com/store/apps/details?id=com.youaddon.suitecrmmobilev2)**  
  Companion mobile app for SuiteCRM via REST API with record management, activity tracking, and advanced search. No data collection, encrypted connections [citation:14].

- **[CRMTiger – vTiger Mobile](https://github.com/crmtiger)**  
  Free mobile app for vTiger CRM 6.5/7.x with GPS sales team tracking, check-in/checkout with location, activity streams, map views, and push notifications. Requires extension installation [citation:12][citation:17].

- **[CustomerDB-Android](https://github.com/schorschii/customerdb-android)**  
  Open-source Android app for managing customers, appointments, and vouchers separately from personal contacts. Self-hosted sync server available, no forced cloud connection, no tracking [citation:1].

- **[EspoCRM](https://github.com/espocrm/espocrm)**  
  Open-source CRM with a native iPhone app (Espo CRM) featuring calling, texting, pipeline management, and push notifications. Same account and data as desktop portal [citation:3].

- **[YouCRM for EspoCRM](https://apps.apple.com/br/app/youcrm-for-espocrm/id6763215695)**  
  Companion mobile app for EspoCRM connecting via REST API with real-time record management, activity tracking, and secure encrypted connections [citation:10].

- **[CRM-Real-Estate](https://github.com/NPSarode/CRM-Real-Estate)**  
  React Native mobile CRM for real estate lead management with lead tracking, status updates, contact management, role-based access, and dashboard insights. Built with React Native and Node.js/PostgreSQL backend [citation:7].

- **[flutter-crm](https://github.com/MicroPyramid/flutter-crm)**  
  Flutter-based CRM mobile app with multi-tenant organization support, Google OAuth authentication, contacts/leads/tasks services, and dashboard. Connects to BottleCRM backend [citation:13].

- **[react-native-crm](https://github.com/RichM1216/react-native-crm)**  
  React Native mobile CRM with user authentication, lead management, and sales pipeline tracking. Under active development [citation:19].

### Additional Strong Open-Source Options

- **[Odoo Mobile](https://github.com/odoo/odoo)** — Native mobile app for Odoo ERP/CRM (Enterprise 16+) with push notifications and access to all Odoo applications including CRM [citation:6][citation:18].
- **[Krayin](https://github.com/krayin/laravel-crm)** — Open-source Laravel CRM with mobile-responsive interface and REST API for custom mobile app development.
- **[EspoCRM Web Shortcuts](https://blog.espocrm.com/tips/shortcut-link/)** — Guide for adding EspoCRM shortcuts to mobile home screen for app-like access without native app [citation:15].
- **Mobile Frameworks** — Flutter, React Native, and Capacitor for building custom cross-platform CRM apps.
- **Offline-First Libraries** — WatermelonDB, PouchDB, and Realm for offline-capable mobile CRM data sync.
- **Business Card Scanning** — OpenCV and Tesseract OCR for custom business card capture.
- **Call Logging** — Android CallLog API and iOS CallKit for CRM call integration.

**Frameworks for building custom systems**: Combine **BottleCRM** or **Twenty** for CRM backend, **Flutter** or **React Native** for cross-platform mobile apps, **WatermelonDB** for offline sync, and **PostgreSQL + Metabase** for CRM analytics to build a complete self-hosted mobile CRM stack.
